# Nix blog surface

Mode: Read. Scope: Markdown pages, file explorer and sidebar search. The user's latest instruction supersedes the earlier large welcome layout and primary navigation. Only the archives submodule supplies writing. It is checked out as root-level content/; this mount point is hidden and its contents appear directly in the explorer. Global settings live in config.yaml.

## Direction contract
THESIS: A compact personal cyber security notebook, navigated by its actual Markdown files.
OWN-WORLD: NirSoft pale-blue sidebar, navy headings, standard blue links, white canvas, Times New Roman 16px reading copy, Arial 12px navigation, square controls.
STORY: Open a folder, read a note, follow an internal reference or search.
FIRST VIEWPORT: 70px Nix masthead, 218px folder sidebar, source-authored Markdown page with no custom homepage or writing index. No primary menu or invented topic folders. Folders open their hidden index pages and expand; when no published index exists, a compact file/date table lists all published descendants by recently added date; extensions and explorer heading are hidden. Mobile navigation collapses. Captions center; header icons fall back to text; the table of contents highlights the current scrolled section.
FORM: User-pinned NirSoft directory, updated from seed 311c3d79. config.yaml controls title, URLs, metadata, content and theme.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
